A tiny chess engine in 4 KB of Python: alpha-beta search with quiescence, a transposition table, killer moves, piece-square evaluation and repetition handling, playing the house gauntlet through the make.fun env. Local practice trials rate about 1365 Elo.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
